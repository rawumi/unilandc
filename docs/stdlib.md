# Стандартная библиотека

Справочник по встроенным функциям `unilandc`. Всё это доступно без импортов: имена
живут в глобальной области. Функции, которые меняют массив (`push`, `sort` и т. п.),
работают на месте и обычно возвращают сам массив или удалённый элемент — как в
JavaScript. Функции без такого замечания возвращают новое значение.

## Печать, ввод, логи

| Вызов | Что делает |
| --- | --- |
| `print(a, b, ...)` | печатает аргументы через пробел и переводит строку |
| `output(a, ...)` | то же самое (алиас `print`) |
| `input([prompt])` | печатает приглашение без перевода строки и читает строку без `\n` |
| `log_debug(...)`, `log_info(...)`, `log_warn(...)`, `log_error(...)`, `log_fatal(...)` | печать с префиксом уровня |
| `exit([code])` | завершает программу с кодом (по умолчанию 0) |
| `argv()` | массив аргументов скрипта после имени файла |
| `env()` | объект со всеми переменными окружения |
| `env(name[, default])` | значение переменной или `default`/`null`, если её нет |

`input()` в конце файла возвращает пустую строку, а не ошибку.

## Типы и преобразования

| Вызов | Что делает |
| --- | --- |
| `typeof(x)` | `"null"`, `"boolean"`, `"number"`, `"string"`, `"array"`, `"object"`, `"function"` |
| `to_string(x)` | строковое представление |
| `to_number(x)` | число; для нечисловой строки — ошибка |
| `to_boolean(x)` | истинность значения |
| `is_null(x)`, `is_boolean(x)`, `is_number(x)`, `is_string(x)`, `is_array(x)`, `is_object(x)`, `is_function(x)` | проверки типа |
| `length(x)` | длина строки (в символах UTF-8), массива или объекта |
| `clone(x)` | глубокая копия массива/объекта |

Истинны: `true`, ненулевое число, непустая строка, непустой массив/объект.
Ложны: `false`, `0`, `0.0`, `""`, `null`, `[]`, `{}`.

## Строки

| Вызов | Что делает |
| --- | --- |
| `uppercase(s)`, `lowercase(s)` | регистр (латиница и кириллица) |
| `trim(s)` | убирает пробелы по краям |
| `split(s)` | режет по пробельным символам, пустые куски выбрасывает |
| `split(s, sep)` | режет по разделителю; `split(s, "")` — посимвольно |
| `join(array, sep)` | склеивает элементы через разделитель |
| `replace(s, old, new)` | заменяет все вхождения |
| `substring(s, start[, end])` | срез по символам, отрицательные индексы считаются с конца |
| `startswith(s, prefix)`, `endswith(s, suffix)` | проверки начала и конца |
| `includes(s, sub)` | есть ли подстрока |
| `indexOf(s, sub)` | байтовая позиция подстроки или `-1` |
| `repeat(s, n)` | повторяет строку `n` раз |
| `char_code(s)` | код первого символа |
| `from_char_code(n)` | строка из кода |

`length`, `substring` и `slice` считают именно символы UTF-8, а не байты;
`indexOf` для строк возвращает байтовое смещение.

## Массивы

| Вызов | Что делает |
| --- | --- |
| `push(a, x)` | добавляет в конец |
| `pop(a)` | снимает последний элемент |
| `shift(a)` / `unshift(a, x)` | снимает первый / добавляет в начало |
| `slice(a, start[, end])` | копия участка, отрицательные индексы — с конца |
| `splice(a, start[, count])` | вырезает `count` элементов начиная со `start` и возвращает их |
| `reverse(a)` | разворачивает на месте |
| `sort(a[, keyfn])` | сортирует на месте; `keyfn` возвращает ключ сортировки |
| `includes(a, x)`, `indexOf(a, x)` | поиск элемента |
| `map(a, fn)` | новый массив из результатов `fn(item)` |
| `filter(a, fn)` | элементы, для которых `fn(item)` истинно |
| `find(a, fn)` | первый подходящий элемент или `null` |
| `each(a, fn)` | вызывает `fn(item)` для каждого, результат отбрасывает |
| `reduce(a, fn[, initial])` | свёртка `fn(acc, item)`; без `initial` берёт первый элемент |
| `sum(a)` | сумма чисел |
| `range(stop)`, `range(start, stop)`, `range(start, stop, step)` | массив чисел, `stop` не включается |
| `min(...)`, `max(...)` | минимум/максимум из аргументов или из одного массива |

`keyfn` для `sort` получает элемент и возвращает число или строку:

```uni
people = [{"name": "Аня", "age": 31}, {"name": "Боря", "age": 22}]
sort(people, fn(p) { return p.age })
print(people[0].name)
```

## Математика

`abs(x)`, `round(x)`, `round(x, digits)`, `floor(x)`, `ceil(x)`, `sqrt(x)`,
`pow(x, y)`, `min(...)`, `max(...)`, `random()`, `random(a, b)`.

`random()` — дробное `[0, 1)`, `random(a, b)` — целое в диапазоне включая границы.
Целые числа произвольной точности: `2^100` считается точно.

## HTTP

Все четыре функции принимают URL и возвращают объект:

```
{"status": 200, "body": "...", "headers": {"content-type": "application/json"}}
```

| Вызов | Что делает |
| --- | --- |
| `http_get(url)` | GET |
| `http_post(url, value)` | POST; `value` уходит телом в JSON |
| `http_put(url, value)` | PUT, тело — JSON |
| `http_delete(url)` | DELETE |

Имена заголовков в ответе приводятся к каноническому виду (`Content-Type`). Ошибки сети и разбора URL
поднимаются исключением.

```uni
try {
    r = http_get("https://api.github.com/repos/golang/go")
    print(r.status)
    data = parse_json(r.body)
    print(data.stargazers_count)
} catch (e) {
    print("сеть недоступна:", e)
}
```

## Python

| Вызов | Что делает |
| --- | --- |
| `pyeval(code)` | вычисляет выражение Python и возвращает результат |
| `pyexec(code)` | выполняет код Python, возвращает `null` |
| `py(code)` | синоним `pyexec` |

Нужен установленный Python в `PATH` (`python` или `py`); иначе — понятная ошибка.

## Go

| Вызов | Что делает |
| --- | --- |
| `goeval(expr)` | вычисляет выражение Go, результат — значение |
| `goexec(code)` | выполняет код Go |
| `gofunc("pkg.Func")` | возвращает функцию-обёртку над функцией Go |

`gofunc` — обратный мост: функция Go вызывается из UniLand как обычная функция.
Аргументы приводятся к параметрам через `reflect`: строка, целое, дробное, `bool`,
`interface{}`. Значение результата приходит в UniLand.

```uni
up = gofunc("strings.ToUpper")
print(up("привет"))            # ПРИВЕТ

rep = gofunc("strings.Repeat")
print(rep("ab", 3))            # ababab
```

При первом вызове воркер `goworker.go` компилируется в `%TEMP%\uniland-goworker-c`
(нужен Go в `PATH`). Кеш сверяется по хешу исходника: после правок воркер
пересобирается сам.

## C

| Вызов | Что делает |
| --- | --- |
| `c_load(path)` | загружает DLL, возвращает handle |
| `c_sym(handle, name)` | адрес символа |
| `c_call(handle, name, signature, ...)` | вызывает функцию |
| `c_free(handle)` | выгружает библиотеку |

Сигнатура — строка вида `"iisi"`: первый символ — тип результата, дальше типы
аргументов. `i` — целое, `d` — дробное, `s` — строка (`char *`). Поддерживается
до 6 целых аргументов или до 4 дробных; смешивать `int` и `double` в одном вызове
нельзя.

## GUI

| Вызов | Что делает |
| --- | --- |
| `gui_window(title, w, h)` | создаёт окно |
| `gui_label(text)` | добавляет подпись |
| `gui_button(text, fn)` | кнопка с обработчиком |
| `gui_input(placeholder)` | поле ввода |
| `gui_get(id)`, `gui_set(id, text)` | читает/меняет текст виджета |
| `gui_run()` | запускает цикл событий (блокирует до закрытия) |
| `gui_close()` | закрывает окно |
| `gui_on_close(fn)` | обработчик закрытия |
| `gui_image(path, w, h[, fn])` | картинка PNG/JPEG/GIF/BMP/ICO; вложенный GIF анимируется, `fn` — клик |

`get_value`, `set_text`, `show_alert`, `show_confirm`, `show_prompt` — старые имена
тех же функций.

Окно одно на процесс. `gui_run()` нужно вызывать один раз в конце настройки.
Без графической сессии (`UNILAND_NOGUI=1`) окна не создаются.

## Модули

`import "путь.uni"` подключает файл: все его переменные и функции становятся
доступны по именам. `import "путь.uni" as ns` кладёт их в объект `ns`.

Путь считается относительным от файла, который импортирует, а не от текущей папки
запуска. Один и тот же файл выполняется один раз, повторный импорт берёт кеш.
Циклы (`a` импортирует `b`, `b` импортирует `a`) — ошибка с понятным текстом.

```uni
import "lib/text.uni"
import "lib/math.uni" as m

print(trim("  привет  "))
print(m.square(5))
```

## Ошибки и трассировка

Ошибка времени выполнения печатает строку и стек вызовов:

```
UniLand error: Error at line 2: Division by zero
Стек вызовов:
  в c(), строка 6
  в b(), строка 10
  в a(), строка 13
```

`uniland run -t script.uni` (`--trace`) печатает в stderr каждый выполняемый узел
и вход/выход из функций:

```
[trace] строка 5
[trace] -> f() строка 5
[trace] строка 2
[trace] <- f()
```

Это полезно, когда непонятно, какая ветка кода сработала: видно порядок строк и
вложенность вызовов.
